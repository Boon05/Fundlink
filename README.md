# FundLink - Student Funding and Scholarship Management System

FundLink is an Android application built with Kotlin, ViewBinding, Navigation Component, Room (SQLite), and Coroutines.

## Features
- **Local Room Database**: Persists users, funding opportunities, and student applications.
- **Role-Based Access**: Student and Officer roles.
- **Secure Authentication**: Salted PBKDF2-SHA256 password hashing and session management.

1. Open the project in Android Studio.
2. Let Gradle sync and download dependencies.
3. Build and run on an Android emulator or physical device (API level 26+).
